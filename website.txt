2. SEE — Computer Vision Projects
01 — GCP Marker Localization & Shape Classification
Category: Aerial Computer Vision · High-Resolution Vision
Description: Multi-task pipeline for localizing and classifying GCP markers in 4096×3000 aerial drone imagery.
Metrics: 20.32 px mean localization error; ~100% shape classification accuracy; ~1.0 Macro-F1; inference across 300 unlabeled test images.
Tech stack: Python, PyTorch, EfficientNet-B3, OpenCV, Albumentations, keypoint-aware augmentation, GroupKFold, tiled inference.
Problem: High-resolution images made small/off-center targets difficult to learn efficiently.
Approach: Used 512×512 crop-based training, keypoint-aware augmentation, leakage-safe GroupKFold by project/survey/GCP, and tiled inference.
Failure / lesson: Random image-level splitting could leak correlated visual information across the same survey/project. Group-based splitting produced a more reliable evaluation.

4. RESEARCH — Experiments
01 — Crop-based learning for high-resolution imagery
Hypothesis: Training on strategically selected 512×512 crops should improve learning of small/off-center GCP markers versus full-image training.
Finding: The EfficientNet-B3 crop pipeline achieved 20.32 px localization error and ~1.0 Macro-F1.
Lesson: For high-resolution imagery, where the model looks can matter as much as what model is used.
02 — Leakage-safe grouping improves evaluation reliability
Hypothesis: Random image-level splitting can overestimate generalization when images originate from the same survey/project.
Finding: Grouping by project/survey/GCP provides a more reliable evaluation setup.
Lesson: Dataset design is part of model design.
03 — Hybrid retrieval for grounded legal/operational AI
Hypothesis: Combining lexical and dense retrieval should be more robust than relying on either alone.
Finding: BM25 + dense retrieval + RRF was used as the grounding layer for the offline cybercrime/legal assistant.
Lesson: Semantic similarity alone is not enough when exact statutory language, terminology, or procedural phrases matter.
Failed Experiments / Research Lessons
Random image-level splitting
Tried: Random train/validation splitting.
Problem: Correlated images from the same survey/project can leak visual information across splits.
Changed: Changed to GroupKFold using project/survey/GCP grouping.
Lesson: Evaluation must model the actual generalization scenario.
Treating industrial CV as purely a model problem
Tried: Focused primarily on model selection.
Problem: Camera motion, shutter behavior, illumination, lens choice, and installation can dominate system performance.
Changed: Expanded the design to global-shutter cameras, camera placement, lighting, depth sensing, and edge hardware.
Lesson: Industrial Computer Vision is an imaging + ML + systems problem.
